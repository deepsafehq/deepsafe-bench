## 1. Get an API Key

Sign up at [localhost:3000](http://localhost:3000) and create an API key from the **API Keys** page.

## 2. Make Your First Request

```bash title="cURL"
curl -X POST http://localhost:8000/v1/detect \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@photo.jpg"
```

## 3. Get Your Result

```json title="Response (200 OK)"
{
  "id": "det_a1b2c3d4",
  "verdict": "fake",
  "confidence": 0.94,
  "media_type": "image",
  "created_at": "2026-03-26T12:00:00Z"
}
```

That's it. The `verdict` field tells you if the media is `real` or `fake`, and `confidence` gives you the probability score (0.0 to 1.0).
