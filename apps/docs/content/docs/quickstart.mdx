## 1. Install

```bash
git clone https://github.com/deepsafehq/deepsafe-bench.git
cd deepsafe-bench
bash setup.sh
```

`setup.sh` pulls roughly 44 GB of model weights and code from HuggingFace. No
token is required; the repositories are public.

Requires a CUDA GPU with 24 GB or more of VRAM for the full lineup, NVIDIA
driver 535+, CUDA 12.1+, and Python 3.11 or 3.12. Load a subset on a smaller
card with `DEEPSAFE_MODELS=npr,aide`.

## 2. Start the server

```bash
# The models
cd apps/inference && PYTHONPATH=.:../../packages/shared python server.py

# The API, in another terminal
cd apps/gateway && PYTHONPATH=.:../../packages/shared uvicorn main:app --port 8000
```

The gateway runs with no configuration at all. It uses SQLite and no
authentication, which is what you want on your own machine.

## 3. Make a request

No API key needed locally:

```bash title="cURL"
curl -X POST http://localhost:8000/v1/detect \
  -F "file=@photo.jpg"
```

## 4. Read the result

```json title="Response (200 OK)"
{
  "id": "det_a1b2c3d4",
  "verdict": "fake",
  "confidence": 0.94,
  "media_type": "image",
  "created_at": "2026-03-26T12:00:00Z"
}
```

`verdict` is `real` or `fake`, and `confidence` is the probability in
[0.0, 1.0]. Treat it as an estimate: see the accuracy figures on the
[overview](/) before acting on one.

Interactive docs are served at `http://localhost:8000/docs`.
