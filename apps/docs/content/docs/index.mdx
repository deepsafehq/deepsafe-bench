## Supported Media

| Type | Formats |
|------|---------|
| Image | JPEG, PNG, WebP, BMP, TIFF |
| Audio | WAV, MP3, FLAC, OGG, M4A |
| Video | MP4, AVI, MOV, WebM, MKV |

Maximum file size: **100MB**.

## Pricing

| Plan | Price | Scans | Rate Limit |
|------|-------|-------|------------|
| Free | $0 | 200 (lifetime) | 5 req/min, 10/day |
| Starter | $29/mo | 2,000/month | 20 req/min |
| Pro | $99/mo | 10,000/month | 60 req/min |

All plans include all media types. 1 scan = 1 file, regardless of type or size.
