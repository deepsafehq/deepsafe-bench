DeepSafe is self-hosted. There is no account, no API key to buy, and no
hosted endpoint. You run it on your own hardware and it answers on
`localhost`.

## Supported Media

| Type | Formats |
|------|---------|
| Image | JPEG, PNG, WebP, BMP, TIFF |
| Audio | WAV, MP3, FLAC, OGG, M4A |
| Video | MP4, AVI, MOV, WebM, MKV |

Maximum file size: **100MB**.

## Read this before you trust a verdict

A detection score is an estimate, not evidence. Measured across 411
generators, the ensemble catches **66.2% of fake media at a 6.5% false
positive rate**, and the misses are concentrated rather than spread evenly:

| Generator | Caught |
|---|---|
| Hunyuan (video) | 1.7% |
| Sora (video) | 7.0% |
| Veo (video) | 8.0% |
| Stable Diffusion 1.4 (image) | 100% |
| Midjourney v5 (image) | 100% |

Detection is strong on the 2022-2023 diffusion models the research was built
around and weak on recent video generators. Do not use a score to accuse
anyone of anything. Full results are in
[BENCHMARK.md](https://github.com/deepsafehq/deepsafe-bench/blob/main/BENCHMARK.md).

When a provenance signal is present, such as a C2PA manifest or a watermark,
it is far stronger evidence than any model score.
