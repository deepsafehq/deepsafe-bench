Base URL: `http://localhost:8000`

## POST /v1/detect

Submit a file for deepfake detection. Returns the result synchronously by default, or a job ID if `async=true`.

### Request

```bash title="cURL"
curl -X POST http://localhost:8000/v1/detect \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@photo.jpg"
```

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `file` | binary | Yes | Image, audio, or video file (max 100MB) |
| `media_type` | string | No | `image`, `audio`, or `video`. Auto-detected if omitted. |
| `async` | boolean | No | Default `false`. Set `true` for async processing (Starter+ plans). |
| `sensitivity` | string | No | Detection sensitivity: `balanced` (default), `strict` (fewer false positives), or `sensitive` (fewer false negatives). |

### Response (Synchronous, 200 OK)

```json title="Response"
{
  "id": "det_a1b2c3d4",
  "verdict": "fake",
  "confidence": 0.94,
  "media_type": "image",
  "created_at": "2026-03-26T12:00:00Z"
}
```

### Response (Async, 202 Accepted)

```json title="Response"
{
  "id": "det_a1b2c3d4",
  "status": "processing",
  "poll_url": "/v1/results/det_a1b2c3d4"
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique detection ID (prefix: `det_`) |
| `verdict` | string | `real` or `fake` |
| `confidence` | float | Probability score from 0.0 to 1.0 |
| `media_type` | string | Detected media type |
| `created_at` | string | ISO 8601 timestamp |

## GET /v1/results/\{id\}

Poll for async detection results. Use the `id` returned from an async `/v1/detect` request.

```bash title="cURL"
curl http://localhost:8000/v1/results/det_a1b2c3d4 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Processing

```json
{"id": "det_a1b2c3d4", "status": "processing", "poll_url": "/v1/results/det_a1b2c3d4", "created_at": "2026-03-26T12:00:00Z"}
```

### Complete

```json
{
  "id": "det_a1b2c3d4",
  "status": "complete",
  "verdict": "fake",
  "confidence": 0.94,
  "media_type": "image",
  "created_at": "2026-03-26T12:00:00Z",
  "completed_at": "2026-03-26T12:00:05Z"
}
```

### Failed

```json
{
  "id": "det_a1b2c3d4",
  "status": "failed",
  "error": "Detection could not be completed. Please try again.",
  "created_at": "2026-03-26T12:00:00Z"
}
```

## GET /v1/usage

Check your current scan usage and quota.

```bash title="cURL"
curl http://localhost:8000/v1/usage \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json title="Response"
{
  "plan": "free",
  "scans_used": 47,
  "scans_limit": 200,
  "scans_remaining": 153,
  "period_start": "2026-03-01T00:00:00Z"
}
```

> Scans are only counted after successful detection. Failed analyses do not consume your quota.
