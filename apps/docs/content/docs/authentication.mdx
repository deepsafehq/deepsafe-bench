---
title: Authentication
description: Optional. Off by default, and how to enable it.
---

Authentication is **off by default**. On a local install you call the API with
no credentials at all, which is the whole point of self-hosting.

Turn it on before you expose the gateway to a network:

```bash
DEEPSAFE_REQUIRE_AUTH=true
```

It is enabled automatically when `DEEPSAFE_ENV=production`, which also requires
a real `DATABASE_URL` and refuses to start without one.

## Getting a Key

Only relevant once auth is enabled. Keys are issued by your own gateway, not
by us:

```bash
curl -X POST http://localhost:8000/api/keys \
  -H "Content-Type: application/json" \
  -d '{"name": "my-key"}'
```

The key is shown once. Store it; only its hash is kept.

## Using Your Key

Include it in every request:

```bash title="Example"
curl -H "Authorization: Bearer ds_live_your_key_here" \
  http://localhost:8000/v1/usage
```

```python title="Python"
import requests

response = requests.post(
    "http://localhost:8000/v1/detect",
    headers={"Authorization": "Bearer ds_live_your_key_here"},
    files={"file": open("photo.jpg", "rb")},
)
print(response.json())
```

```javascript title="Node.js"
const form = new FormData();
form.append('file', fs.createReadStream('photo.jpg'));

const response = await fetch('http://localhost:8000/v1/detect', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer ds_live_your_key_here' },
  body: form,
});
const result = await response.json();
```

## Key Management

- Up to **5 keys** per user, for separate environments (dev, staging, prod)
- Revoke a compromised key with `DELETE /api/keys/{id}`
- Revoked keys return `401 Unauthorized` immediately
- Keys belonging to one user share a quota, so quota is per-user, not per-key

## Security Best Practices

- Keys are hashed (SHA-256) before storage. The plaintext key is never persisted,
  by your own gateway or anyone else.
- Use environment variables to store keys, never hardcode them
- Rotate keys periodically
- Use separate keys for development and production
